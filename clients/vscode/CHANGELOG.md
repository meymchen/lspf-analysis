# Changelog

## 0.1.0 (preview)

- Analyze code health for C++, Java, JavaScript, Python, Rust, TypeScript,
  and TSX with a bundled language server.
- Show function measurements in hovers and report low scores in Problems.
- List functions in the Code Health tree, sorted by quality or source order.
- Show a file summary and navigation links in the status bar.
- Score Java classes and interfaces using class design metrics.
- Configure scoring thresholds, relative weights, and diagnostic visibility.
- Support English and Simplified Chinese throughout the extension.
